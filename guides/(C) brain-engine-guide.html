Activation Guide
Three steps to run the brain hands-off all day
01
Seed the inputs
Drop any content into the vault. Doesn't need to be clean or organized — that's the triage agent's job.
  • Raw data exports (CSV, JSON) → 00 Raw Inputs/
  • Half-formed ideas, URLs, voice note transcripts → 00 Notes/
  • Screenshots, PDFs, anything → anywhere in the vault, triage will find it
  • Type research requests directly into QUEUE.md — the loop picks them up
02
Start the Fable loop
Paste this into Claude and walk away. The loop self-paces using ScheduleWakeup — it processes, sleeps, wakes, repeats until the queue is clear.
/loop process all new vault content # Claude runs: triage → research → linker in sequence # Self-paces every ~4 min · notifies when done
03
Crons handle the schedule
Daily briefing and Sunday synthesis are already running this session. For the next session, Claude re-registers them on startup — or you type "register my crons."
register my crons # Re-activates daily briefing (6:03am) + weekly synthesis (Sun 8:47am) # Add this to session startup if you want auto-registration

Why Tailscale, not port-forwarding: Tailscale builds a private WireGuard mesh between only your own devices — no router config, no public IP exposure, works through any network including cellular. Port 8080 is never open to the public internet, only to devices logged into your tailnet.
01
Confirm the server runs locally
brain-server.js already exists at the MainBrain root. Start it and confirm it serves the widget stack before wiring up remote access.
cd "C:\Users\james\OneDrive\Desktop\MainBrain" node brain-server.js # Look for "🧠 James Brain Server — running", then open http://localhost:8080
  • Verified 2026-07-03 — responds 200 OK on localhost and on the LAN IP it prints
  • Ctrl+C stops it. This manual start does NOT survive reboot — Step 07 fixes that
02
Install Tailscale on Windows
This machine is the server, so it joins the tailnet first.
winget install tailscale.tailscale tailscale up tailscale ip -4 # `tailscale up` opens a browser — log in with whichever account (Google/Microsoft/GitHub) # you'll use on every device. The ip -4 output is this PC's permanent tailnet address, e.g. 100.x.x.x
03
Install Tailscale on Mac
Same tailnet account as Windows.
brew install --cask tailscale # no Homebrew? download the .pkg from tailscale.com/download/mac instead # open Tailscale from Applications → Sign in → same account used on Windows
04
Install Tailscale on iPhone
Same tailnet account again — this is what lets the phone reach the brain with no VPN app open in the background.
App Store → search "Tailscale" → Install # Open app → Sign in with same account → tap Connect # Allow the VPN configuration prompt — this is a private tunnel, not a public VPN
05
Enable OpenSSH Server on Windows
Needed so VS Code on the Mac can open a full remote coding session on this PC — same as sitting at the machine.
# Run PowerShell AS ADMINISTRATOR Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0 Start-Service sshd Set-Service -Name sshd -StartupType Automatic New-NetFirewallRule -Name sshd -DisplayName "OpenSSH Server (sshd)" -Enabled True -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22
  • Note your Windows username: whoami
  • Re-confirm the tailnet IP if needed: tailscale ip -4
06
Connect VS Code Remote-SSH from Mac
One-time config, then it's a dropdown in VS Code from then on.
# On the Mac, in Terminal — append a host entry: cat >> ~/.ssh/config << 'EOF' Host mainbrain   HostName <windows-tailscale-ip>   User <windows-username> EOF
  • Install the "Remote - SSH" extension in VS Code on the Mac
  • Cmd+Shift+P → "Remote-SSH: Connect to Host" → mainbrain
  • First connection prompts for the Windows password — VS Code then opens a remote window rooted on this machine's filesystem
07
Make brain-server.js persistent
Right now the server only runs while its terminal window stays open. This registers it as a Windows Scheduled Task that starts automatically at login and keeps serving in the background — no window, survives reboot.
# Run PowerShell AS ADMINISTRATOR cd "C:\Users\james\OneDrive\Desktop\MainBrain" .\setup-auto-start.ps1 # Registers scheduled task "JamesBrainServer" → runs node brain-server.js at every Windows logon powercfg /change standby-timeout-ac 0 # Stops the PC sleeping while plugged in, so it's reachable any time, not just right after login
  • Test immediately without rebooting: Start-ScheduledTask -TaskName "JamesBrainServer"
  • Confirm it's live: Get-NetTCPConnection -LocalPort 8080
  • For it to survive a full cold reboot (not just screen lock), set Windows to auto-login via netplwiz
08
Verify end-to-end from Mac + iPhone
With Tailscale connected on both devices, the widget stack is one URL away.
http://<windows-tailscale-ip>:8080 # iPhone Safari: open the URL → Share → Add to Home Screen for an app-like icon
  • Doesn't load? Allow the port through Windows Firewall: New-NetFirewallRule -DisplayName "Brain Server 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
  • Tailscale IPs are stable per-device — bookmark it once, it won't change
  • Optional: enable MagicDNS in the Tailscale admin console to use a name instead of an IP
09
Edit live via Claude Code / Codex through Remote-SSH
Step 06 doesn't just give the Mac a file browser — it opens a real terminal running ON the Windows machine. That terminal is where you run Claude Code or Codex, exactly like sitting at the PC. One file, edited there, is the same file brain-server.js is already serving.
# In the Remote-SSH VS Code window (connected to "mainbrain"): File → Open Folder → C:\Users\james\OneDrive\Desktop\MainBrain Ctrl+` # opens the integrated terminal — it runs on Windows, not the Mac claude # same Claude Code session as sitting at the PC — same memory, skills, agents, MCP connectors
# Codex (OpenAI's CLI agent) — install once on Windows if you want a second agent: npm install -g @openai/codex codex # separate auth (ChatGPT/OpenAI login) — check `npm view @openai/codex` if this has moved
  • No server restart needed for HTML/CSS/JS edits — Cache-Control: no-cache means the next refresh on Mac or iPhone shows the change instantly
  • Only editing brain-server.js itself needs a restart: Stop-ScheduledTask -TaskName "JamesBrainServer"; Start-ScheduledTask -TaskName "JamesBrainServer"
  • This works from anywhere the Mac has Tailscale — same coffee shop, same edit-and-refresh loop as sitting at the Windows desk
