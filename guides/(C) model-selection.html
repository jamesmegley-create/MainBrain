Mapped to Your Work
Task TypeModelWhy
Widget/dashboard code (brain-server.js, HTML/JS) Sonnet 5 Best agentic coding tradeoff — this is what you're already on.
NextGrid legal-framework drafting Opus 4.8 High-stakes, low error tolerance, needs deepest reasoning.
Director-mode cross-domain synthesis (trading vs. Ironframe vs. Filevine vs. NextGrid leverage) Opus 4.8 Exactly the "weigh many domains, find the non-obvious move" reasoning Opus is built for.
Triage/capture, ss state updates, quick file edits, v verify checks Haiku 4.5 Fast, cheap, low ambiguity — or Sonnet with Fast mode.
Content drafts (LinkedIn, TikTok @brainwifi voice) Sonnet 5 Try Fable 5 for a more natural/creative tone — untested, worth an A/B.
Trading review / methodology analysis Sonnet 5 Default for routine review — escalate to Opus for anomaly/edge-case reasoning.
Quick Heuristic
Routine + well-defined → Haiku.
Everyday build/edit work → Sonnet — your default, stay here.
High-stakes, ambiguous, or "connect 4+ domains" → Opus.
Next action: Keep Sonnet 5 as default. Next time you run a director-mode cross-domain leverage call (e.g. "what's the fastest path to $X"), run it once on Opus 4.8 and compare — that's the task most likely to justify the switch.
